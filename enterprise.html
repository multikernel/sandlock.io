Enterprise

Deploy Sandlock in Production

Sandlock is Apache-2.0 licensed and free to run at any scale, with no license key, no seat count, and no telemetry. What we sell is the engineering work of getting it right in your environment.

How to get it

Two Ways to Adopt

Most teams start with the open-source project and stay there. Platform teams putting Sandlock on the critical path of a product usually want us in the room.

Open source

Build it and run it

Clone the repository, build with Cargo, and deploy on any Linux 6.12 host. The full feature set is in the open-source project. There is no paywalled tier, no enterprise-only flag, and no runtime that phones home.

Complete CLI, Python, Rust, and Go interfaces
OCI runtime for containerd, CRI-O, and Kubernetes
MCP server for AI agent tool execution
Community support through GitHub issues

Who builds it

Multikernel Technologies

Sandlock is built and maintained by Multikernel Technologies, a systems company working on Linux kernel isolation. Our engineers contribute upstream to the kernel, which is also where several of Sandlock's foundations live.

Upstream first

Sandlock is built on Landlock and seccomp as they ship in mainline Linux. There is no out-of-tree module to install and no patched kernel to maintain, so your kernel upgrade path stays yours.

The other half of the problem

When a shared kernel is not a boundary you can accept, Multikernel's split-kernel architecture gives each workload its own Linux kernel on dedicated cores, with no hypervisor. Same company, stronger boundary, higher cost.
